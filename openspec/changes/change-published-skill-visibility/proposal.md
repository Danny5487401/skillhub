# 已发布技能独立调整可见范围

## Why
Issue #951：当前必须重新上传包才能改变可见范围。用户需要在保持技能标识、发布版本和统计不变的情况下调整访问范围。

## What Changes
- 维护者可从现有技能管理入口调整 PUBLIC、NAMESPACE_ONLY、PRIVATE。
- 缩小范围立即生效；扩大范围进入现有统一技能审核，批准前继续使用原范围。
- 可见范围申请与待审内容版本互斥，支持在现有审核进度中撤回。
- 所有入口继续遵守访问控制、安全扫描、头像受众审核和操作审计。
- 我的技能列表同时说明当前生效范围与待审目标；提升后通过真实关联区分团队来源和全局发布记录。

## Impact
后端 ReviewTask、技能生命周期、发布互斥、搜索投影；Web 管理入口和统一审核详情；API 类型及用户文档。
