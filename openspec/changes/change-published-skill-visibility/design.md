# 设计

- 扩展现有 SKILL_METADATA ReviewTask，为范围申请保存原范围、目标范围、绑定已发布版本；不新增独立审核队列。
- 技能行锁协调提交、发布和审核；范围申请不修改 SkillVersion 状态和 latestVersionId。
- 审批 CAS 保留现有冲突机制。成功改变范围后通过专用范围变更事件复用现有搜索重建，避免重复发送内容更新通知；审计区分提交、通过、拒绝、撤回。
- Web 复用管理交互与统一审核详情；展示当前范围和申请范围。
- 我的技能响应按当前页技能批量投影管理状态，提供待审范围及真实来源／全局关联。不得逐卡拉取审核或提升详情，不从同名推断关联；公共市场、收藏等摘要不附带这些私有管理信息。相关技能无访问权限时不暴露其坐标或跳转。
- 团队来源与全局发布仍是独立记录，可分别更新；列表只解释现有关系，不引入自动同步或删除联动。市场维持现有收录范围，私有技能在“我的技能”维护。
- 业务约束在服务代码与测试维护，迁移只增加必要列，不增加 SQL CHECK。
- 已发布 PRIVATE 版本没有可复用的安全通过结果时，复用 ScanTask/outbox 对已存 bundle 重新扫描，保留 PUBLISHED 状态。范围申请绑定这一次 taskId；旧结果不能解锁新申请，未完成或不安全结果不能批准。scanner 关闭且需要新扫描时明确拒绝，不改变原范围。
