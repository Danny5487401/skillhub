# SkillHub 社区 Skill 同步

本文统一描述社区仓库同步中的产品术语，避免把自动获取上游内容与自动公开混为一谈。

## 同步与发布

**自动同步**：服务端自动发现或检查上游仓库变化，固定变更内容，生成 SkillHub 新版本，并提交安全扫描和人工审核。
_避免_：自动发布、自动替换已发布版本

**人工审核**：授权审核人对新 Skill 或内容变化后的新版本做出发布或拒绝决定。同步服务本身不能代替审核人。
_避免_：机器审核（仅指自动化策略或扫描）

**自动发布**：新版本未经过人工审核就对目标受众可见。本需求首期不允许。
_避免_：自动同步

## 来源与同步状态

**发现候选**：搜索规则或精选 GitHub 账号返回、尚未确认含有效 Skill 的公开仓库线索；它还不是纳入持续同步的正式来源。
_避免_：把搜索命中直接称为已导入来源

**正式来源**：已纳入某个 namespace 的持续同步账本的 GitHub 仓库；管理员明确登记的仓库可在首次扫描前进入该状态。
_避免_：把正式来源等同于已发布 Skill

**权威同步来源**：唯一允许为某个 SkillHub Skill 提供同步内容和后续版本的外部来源绑定；其他同名或重复内容来源不会自动成为更新源。
_避免_：多个主来源

**来源绑定**：将 GitHub 仓库中的一个 Skill 路径关联到一个 SkillHub Skill，并记录上游身份与同步进度。
_避免_：按 Skill 名称推断关联

**来源身份**：由 GitHub 仓库 ID 和 Skill 路径标识；内容 Hash 用来比较快照，不单独证明两个路径属于同一个 Skill。路径移动时，仅同仓库内唯一匹配的完整技能包 Hash 可自动作为改绑依据。
_避免_：用 `SKILL.md.name` 或单个文件 Hash 作为唯一身份

**技能包内容 Hash**：对完整 Skill 包快照计算的内容指纹，用于发现内容变化和辅助识别路径移动；不替代来源身份。
_避免_：只比较 `SKILL.md` 文件

**上游托管内容**：同步 Skill 的正文和文件由上游来源维护；SkillHub 负责扫描、审核、发布和可见性治理。需要定制时应创建独立副本。
_避免_：直接编辑同步副本

**同步暂停**：可停止仓库的后续检查；单个 Skill 路径通过来源忽略规则排除，暂停不改变关联 Skill 的发布、归档、隐藏或可见性状态。
_避免_：暂停发布、自动归档

**目录忽略规则**：用于排除仓库中不应发现或同步的 Skill 路径；平台默认规则包含测试目录，管理员还可在后台按来源添加或覆盖规则。命中已有绑定时停止该来源的后续同步并保留本地 Skill；取消忽略后重新对账。
_避免_：删除已导入技能

**上游不可达**：来源连续无法通过公开接口读取，经 24 小时和 3 天复查仍失败后进入不可达状态；此状态不等于 SkillHub Skill 已删除或应停止分发，来源仍每 7 天复查并在恢复后重新对账。
_避免_：自动归档、自动删除、永久停止检查

**已取代的待审目标**：某个上游快照因发现更新的 revision 而不再允许审核或批准；原快照保留审计记录，新快照成为当前审核目标。
_避免_：覆盖原待审快照、过期版本仍可批准

## 官方探索

**技能同步**：统一管理公开仓库发现、技能采集和后续内容更新的业务能力；同步后的新版本仍按既有规则扫描和审核。
_避免_：把技能同步与深度探索作为两套并列产品

**深度探索**：平台内置并维护发现策略的公开 GitHub 技能仓库发现方式；管理员以少量配置控制持续探索。
_避免_：一次性抓取、自动发布、所有来源同步的总开关

**探索停用**：停止该探索途径的新仓库发现，不等于暂停已登记来源的后续更新。
_避免_：来源停用、删除技能


**指定仓库**：管理员明确指定要持续检查和采集的公开仓库，不代表技能已通过质量、安全或发布审核。
_避免_：精选仓库（旧界面名称）、已认证仓库、已审核技能


**平台采集暂停**：暂停平台@github的新发现、检查和下载，并让在途采集到安全检查点停止；不暂停TEAM采集、已接收包处理、人工审核或已发布技能使用。
_避免_：暂停全部同步、全局暂停、自动探索停用
