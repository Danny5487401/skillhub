## Why

PR #957 支持包内展示名称，但网页不能填写，更新待审时“我的技能”仍显示旧标题并重复展示发布和审核状态，详情缺少完整技能标识。

## What Changes

- 网页新增/更新技能时可填写展示名称；上传后从包内 metadata.display-name（缺省 name）预填，用户输入优先。
- 表单名称作为版本元数据快照保存，不修改上传 ZIP 或 SKILL.md。CLI 继续采用包内字段。
- 管理列表展示待审更新的名称和摘要，使用一个主状态；公开页面保持已发布信息。
- 详情展示完整 @namespace/slug 和复制入口，所有者预览明确标识未公开。

## Scope

沿用现有版本审核、撤回、提升和权限。无独立改名流程、无新数据库迁移，不改变 slug 或下载包内容。
