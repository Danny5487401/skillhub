# 任务记录与归档

适用于已有任务的收尾和worktree清理；任务、运行状态、个人报告不属于公开规范。

- 按已配置的本地执行入口读取归档工具说明，保存当前单个任务的摘要、原始记录与证据链接。
- 摘要说明结果、仓库/分支、提交或PR（若有）、验证范围与未完成项；未提交和未验证如实记录。
- 清理前保存到worktree外，验证目标可读、内容完整。失败保留源记录，不继续依赖归档成功的清理。
- 检查凭证和私人数据；链接报告优于复制源码和环境文件。归档不授予提交、推送或删除权限。
- 稳定任务写入后再快照，不覆盖同标识但不同内容的记录。
- 未配置工具时不假设本机命令存在，说明缺口并保留原记录。没有任务记录不强制创建。

工具路径、参数和私有档案由本地工作流或执行Skill配置，不成为公开规范硬依赖。
原生archive可能修改状态、移动目录、触发hooks或提交；运行前核对，不把它等同跨worktree备份。
验证观察已保存摘要和原始记录；Git clean不证明忽略的任务文件已经保存。
