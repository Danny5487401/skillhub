# 状态归属与会话边界

适用于筛选、表单、缓存、跨组件状态、登录登出及命名空间切换。

| 状态 | 默认归属 | 边界 |
|---|---|---|
| 远端数据、缓存、失效 | TanStack Query | 不另复制一份到 Zustand 并靠 Effect 同步 |
| 可分享、刷新后应恢复的筛选/分页 | 路由 URL | 解析、默认值和查询参数一致；检查前进/后退 |
| 编辑中的表单、弹层开关 | 组件或所属功能状态 | 草稿有独立生命周期；不要被后台刷新覆盖 |
| 多组件共享的本地/UI状态 | 现有 Zustand 或所在功能共享状态 | 明确所有者、重置时机；不为单组件临时值建全局 store |
| 可由上述数据推导的值 | 计算结果 | 避免维护第二份可漂移状态 |

已有页面未使用 URL 的状态，不在纯文档迁移时改变产品行为；新增可分享状态先确定路由契约。
服务端数据被复制为用户可编辑草稿时，明确初始化、保存、放弃及远端变更冲突的处理。

## 身份、权限与资源切换契约

- 用户私有缓存应按身份分区，或在会话变化时清理；选择方案时涵盖在途请求和切换后重新订阅。
  不允许用户 B 看见用户 A 的私有结果。客户端角色判断用于展示，不能代替服务端授权。
- 命名空间、资源、语言影响响应时，纳入缓存身份或有等价失效机制。资源切换需清理旧选择、草稿、
  乐观状态；是否保留草稿按产品契约判断，不静默丢弃用户输入。
- 禁用查询只控制取数，不自动证明缓存已清除；旧数据保留只适用于允许沿用的上下文，不能跨越身份边界。
- Mutation 成功后更新或失效相关数据，失败后不能显示未成功的服务端状态。具体见[Hook 契约](./hook-guidelines.md)。

## 已有实践与证明范围

[通知会话工具](../../../web/src/features/notification/notification-session.ts)按用户分区通知键，并清理一组
会话相关查询；[测试](../../../web/src/features/notification/notification-session.test.ts)验证分区及保留公共搜索缓存。
[会话建立 Hook](../../../web/src/features/auth/use-session-bootstrap.ts)先调用清理再写入当前用户。
这些锚点不证明所有接口均已覆盖身份切换：新增私有查询要核对它是否进入这条机制。

[语言缓存键](../../../web/src/shared/hooks/query-keys.ts)展示语言维度；不要把一个键工厂推广为所有响应都依赖语言。
验证应覆盖相关的账号切换、资源快速切换、浏览器前进/后退、未保存表单与后台刷新，方法见
[前端测试](../testing/frontend-testing.md)。
